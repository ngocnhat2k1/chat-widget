💻 Cách sử dụng

1. Tự động mount (khuyến nghị):

<!-- Thêm script này vào website của bạn -->
<script 
  src="https://your-domain.com/chat-widget.js"
  data-chat-widget-api-key="your-api-key"
  data-chat-widget-domain="your-domain.com"
  data-chat-widget-theme="light"
  data-chat-widget-position="bottom-right"
  data-chat-widget-color="#2563eb"
  data-chat-widget-welcome="Xin chào! Tôi có thể giúp gì cho bạn?"
></script>

2. Manual mount:

<script src="https://your-domain.com/chat-widget.js"></script>
<script>
  window.ChatWidget.mount('chat-widget-container', {
    apiKey: 'your-api-key',
    domain: 'your-domain.com',
    theme: 'light',
    position: 'bottom-right',
    primaryColor: '#2563eb',
    welcomeMessage: 'Xin chào! Tôi có thể giúp gì cho bạn?'
  });
</script>

💡 Lưu ý: Widget này đang ở chế độ demo. Để sử dụng thực tế, bạn cần backend server và API key hợp lệ.
