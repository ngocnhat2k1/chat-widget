💬 Chat Widget

Live Chat Widget Demo

Đây là demo của Chat Widget - một widget chat thời gian thực được xây dựng với React, TypeScript và Socket.IO

Widget đang chạy và sẵn sàng sử dụng!

🚀 Shadow DOM

Cô lập hoàn toàn, không xung đột CSS với website chính

⚡ Real-time

Nhắn tin thời gian thực với Socket.IO

🎨 Customizable

Tùy chỉnh màu sắc, vị trí và giao diện

📱 Responsive

Hoạt động tốt trên mọi thiết bị

💡 Hướng dẫn sử dụng:

1. Widget chat sẽ xuất hiện ở góc dưới bên phải
2. Click vào icon để mở/đóng chat
3. Nhập tin nhắn và nhấn Enter để gửi
4. Trong production, widget sẽ kết nối với backend API
